# Color Rationale

Candidate color: `#1D1A2F`

`#1D1A2F` is the deep EVA-01 purple (near-black violet) — infernal, recognizable,
and distinct from neutral gray while remaining legible as a small GitHub
language-bar segment against both light and dark themes. It is a proposal for a
new language, not a request to change an existing language color; the current
contributing rules require community consensus for the latter case only.

Status: VERIFIED as a syntactically valid `#RRGGBB` proposal. Community
endorsement is NOT_DEMONSTRATED and is not documented by current Linguist rules
as a prerequisite for a new-language color.
